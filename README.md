# KAMOX Chat для iPhone

Приложение-оболочка мессенджера KAMOX Chat (https://kamox123.github.io/chat). Собирается само на облачном Mac GitHub
при каждом изменении; готовый файл — в разделе **Releases → latest → KAMOX-Chat.ipa**.

**Скачать:** [KAMOX-Chat.ipa](https://github.com/kamox123/kamox-chat-ios/releases/download/latest/KAMOX-Chat.ipa)

## Как установить (бесплатно, с компьютера на Windows)
1. Установите **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store) и **Sideloadly** с sideloadly.io.
2. Подключите iPhone кабелем, на iPhone нажмите «Доверять этому компьютеру».
3. В Sideloadly перетащите `KAMOX-Chat.ipa`, впишите свой Apple ID, нажмите **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
5. На iPhone с iOS 16 и новее: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить.

С бесплатным Apple ID приложение работает 7 дней — потом снова нажать Start в Sideloadly (или включить в нём автопродление).

В этой версии нет уведомлений, когда приложение закрыто (Apple даёт их только платным разработчикам). Если нужны уведомления — 
откройте сайт в Safari → «Поделиться» → «На экран Домой».
